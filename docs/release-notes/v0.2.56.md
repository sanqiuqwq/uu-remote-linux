### 变更 / Changed
- **允许他人远程协助**：主机每次启动即自动允许他人远程协助，无需再打开窗口手动切换；本次运行中仍可在窗口/托盘关闭，`UU_ASSIST_ALLOW=0` 可让启动时保持关闭。/ The host allows remote assistance automatically on every start; the window/tray switch still turns it off for the current run, and `UU_ASSIST_ALLOW=0` keeps it off at startup.
- **允许同账号控制本设备**：控制端每次启动时自动启用本机被控服务（`uuremote-native.service`），设置页开关仍可关闭，`UU_VIEWER_HOST=0` 不自动管理。/ The viewer enables the host service (`uuremote-native.service`) automatically on every start; the Settings switch still turns it off, and `UU_VIEWER_HOST=0` leaves it unmanaged.
