修复已保存的投屏授权失效导致无法远程控制。/ Fix remote control failing when a saved screen-share grant no longer yields a monitor.

### 修复 / Fixed
- **GNOME/Wayland Portal**：已保存的屏幕共享授权过期或不匹配当前显示器布局时，Portal 会返回 0 个画面，主机报 `Portal single monitor and keyboard/pointer permission required (code 6)` 并断开。现在会自动丢弃这次授权、重新弹出共享对话框请求一次；用户同意后恢复远程控制。/ When a persisted ScreenCast grant returns no monitor (stale restore token or changed monitor layout), the host now asks the portal again instead of disconnecting with code 6.
- 修复后首次连接需要在本机确认一次共享对话框；之后沿用新的授权。
